都在这条栏上

任务栏不只是一排图标。它接管了系统的位置，也接管了每天要点的那几处。

玻璃任务栏

实时取桌面颜色做模糊与折射，鼠标靠近图标时整条栏跟着伸展，指针下的图标放大。自动贴边隐藏，靠近屏幕底边才出来。

日历与课表

月视图和周课表在同一个窗口切换。课表按周记录，可以只调整某一周。点开某一天，会弹出当天的待办列表。

当日待办

没有系统标题栏的小窗，大小会被记住。切换日期时窗口内容跟着换，不用反复开关。支持标签、提醒和循环待办。

灵动岛

屏幕顶部的一条浮岛，集中待办、剪贴板、音乐波形、翻译和消息提醒。设置在桌面「灵动岛」页里改，不另占托盘图标。

通知与托盘

系统通知变成栏上弹出的玻璃卡片，托盘图标整组收进 Yunzhao 自己的面板，右键菜单与 Windows 一致。

多显示器

每块屏幕一条栏，或只留主屏。可以跟着鼠标走，也可以固定在某一台显示器上。组件的放置单独设置。

三步就能用

不是安装程序，是一个文件夹。想换回系统任务栏，退出就行。

1

下载并解压

把 zip 解压到任意文件夹，例如 D:\Yunzhao。不必放进 Program Files。

2

运行 Yunzhao.exe

首次启动会接管系统任务栏。想退出时右键托盘图标选「退出」，系统任务栏会立刻恢复。

3

登录账号

登录后可把待办、设置和组件布局同步到其他电脑。换机器时登录同一账号即可拉回。

系统要求

需要独立显卡或较新的核显，玻璃效果依赖 D3D11 与 DirectComposition。

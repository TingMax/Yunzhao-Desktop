Yunzhao
桌面 日历 账号

一块自己的 Windows 桌面。

Yunzhao 打开之后，屏幕上是它自己的任务栏、日历、课表和当日待办。设置、账号和教师工作台用的是同一套界面。

下载 Windows 版 2.6.12 · Windows 11 · 336 MB

这是一个压缩包。解压后运行 Yunzhao.exe。账号和数据留在这台电脑上。

任务栏

Yunzhao 使用自己的任务栏。它会自动隐藏，鼠标靠向屏幕边缘时再出现。

日历和课表

日历和课表在同一个窗口里切换。课表按周显示课程，也可以只改某一周。点开某一天，会弹出这一天的待办。

当日待办

待办可以新建、编辑和完成。窗口没有系统标题栏，大小会记住。换一天时，打开的列表跟着换成那一天。

灵动岛

灵动岛是单独的程序，由 Yunzhao 启动。它的设置在桌面的「灵动岛」页里，不另占一个任务栏图标。

账号

登录使用 yunzhao-desktop.com。退出时先上传这个账号要同步的内容，再次登录时再拉回来。登录状态只留在这台电脑上。

数据留在本机

日历、课表和设置写在这台电脑的用户目录里。更换程序时，这些内容留在原地。

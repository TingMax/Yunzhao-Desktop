# Yunzhao

Yunzhao 是一套跑在 Windows 11 上的桌面。打开之后，屏幕上是 Yunzhao 自己的任务栏、日历、课表和当日待办；设置、账号和教师工作台用的是同一套界面。程序名是 `Yunzhao.exe`。

数据放在本机的 `%LOCALAPPDATA%\Yunzhao`。账号登录的是 [yunzhao-desktop.com](https://yunzhao-desktop.com)。代码仓库是 [TingMax/Yunzhao-Desktop](https://github.com/TingMax/Yunzhao-Desktop)。

## 桌面

Yunzhao 运行时使用自己的任务栏。任务栏自动隐藏，鼠标靠向屏幕边缘时出现。它不另外注册开机启动，开发构建也不修改 Windows 的启动项。

桌面上的日历和课表是一组组件。它们平时位于普通窗口下面，按 Win+D 显示桌面时会回到前面。组件可以拖到桌面上；拖动时能看到跟随鼠标的影子。贴到屏幕上边或左右两边时会收起，下边不收。日历默认留在放下它的那块屏幕上，不会自己跑到另一块屏幕。

日历和课表在同一个窗口里切换。课表按周显示课程，也能记下调课。双击某一天，或者从工具栏打开，会另外弹出「当日待办」。这个窗口没有系统标题栏，可以拖动改变大小，大小会记住。在日历或课表上再点别的日期，已经打开的当日待办会换成那一天，而不是再开一个窗口。里面仍然是原来的日期、条数、天气、黄历和待办：可以新建、编辑、完成，收起则关闭这个窗口。

## 灵动岛

灵动岛是 Yunzhao 仓库里的独立程序，进程名仍是 `focusd-island.exe`，不编进 `Yunzhao.exe`。Yunzhao 启动它，设置嵌在「灵动岛」页里，不单独占一个任务栏图标。源码在 `third_party/fly-island`，许可证是 GPL-3.0。

## 设置

设置窗口的页面有：

- 材质、形状、任务栏、通知、状态栏、时间
- 组件：把日历、课表放到桌面
- 灵动岛
- 教师工作台
- 显示器、系统
- 账号
- 设计语言
- 关于：版本、软件更新、设置文件位置

「关于」里的软件更新会向 yunzhao-desktop.com 查询。自动检查在后台进行，不弹窗。

## 账号

用 Yunzhao 账号登录。退出时会先把需要同步的桌面内容上传，再清除本机登录状态。再次登录后把云端内容拉回来。登录状态只保存在本机当前用户下，不明文存放。

## 教师工作台

教师工作台不再单独做一套登录。打开后读取 Yunzhao 已经登录的账号，页头显示这个账号的名称、用户名和邮箱。没有桌面登录时，页面只提示先在 Yunzhao 登录。

## 软件更新

自动更新每 12 小时做一次：

1. 先访问 yunzhao-desktop.com，确认服务器是否通。
2. 不通就取消正在下载的包，不提示、不报错。
3. 通了就读取 `https://yunzhao-desktop.com/releases/latest.json`。只接受 `channel` 为 `main`、文件名为 `Yunzhao-<版本>-win-x64.zip`、地址在这个域名 `/releases/` 下的正式包。
4. `dev` 和其他渠道的包不会下载。

网页上的下载按钮和软件更新用的是同一份压缩包。它是一个文件夹，不是 Windows 安装程序。换上去的是程序本身；`%LOCALAPPDATA%\Yunzhao` 里的账号和数据留在原地。

打开「关于」后，没有新版本时显示「软件暂无更新」。有新版本时显示「功能样式已更新，是否需要安装」，按钮变成「点击安装」。以后发版时，把测过的 `dev` 合进 `main`，再把这个 zip 和 `latest.json` 放到服务器的 `/releases/`。

## 分支

日常改动都在 `dev`。只有明确要求推送到 `main` 时，`main` 才会更新。紧急修复也要在当次说清楚，否则仍然先走 `dev`。

## 构建

在仓库根目录执行：

```powershell
tools\build.ps1 -Development
```

需要 Visual Studio 2022 的 C++ 构建工具，以及 .NET 10。开发版输出在 `dist\Development\Atrium\Yunzhao.exe`。

日历、课表和当日待办在开发时由 `tools\yunzhao-note.ps1` 启动。这个开发服务不是自动更新包的一部分。
